# react-patterns

## Purpose
Apply maintainable React patterns for components, state, effects, and rendering.

## When to use
Activate when the user asks to: React component; hooks; state management.

Category: Stack-specific / Productivity.

## Workflow
Inspect React version, framework, and conventions. Keep components focused, derive rather than duplicate state, use effects for external synchronization, follow hook rules, use stable keys and accessible semantics, and optimize renders only when measured. Test observable behavior.
